# План MiniDb

1. Лексер и рекурсивный парсер: AST, позиции ошибок, тесты приоритетов.
2. Исполнение: CRUD, типы, PK, фильтры, сортировка, агрегаты и группы; тесты SQL.
3. Диск: бинарные страницы 4096 байт, схема и строки, проверка повторного открытия.
4. Индексы: собственное B-дерево с дубликатами, сохранение, EXPLAIN и согласованность.
5. Транзакции: BEGIN/COMMIT/ROLLBACK, WAL, оборванный хвост, тест с убийством процесса.
6. JOIN: nested loop с квалифицированными именами; итоговые тесты, benchmark 100000 строк, документация и демонстрация.

Каждый этап завершается сборкой, подходящими тестами и отдельным коммитом. Итоговые критерии: dotnet build/test проходят, пример задания работает, аварийный тест использует реальный процесс, ускорение измерено без генерации данных внутри замера.
